Validators update the form status. Validation message display is planned; errorMessages currently has no visual effect.

API

Bind with formControl or formControlName. Use control.disable() and control.enable() to change the disabled state.

Accessibility

Always supply a meaningful label. Material associates the label and hint with the native input. Readonly fields remain focusable; disabled fields are skipped during keyboard navigation. Use autocomplete to help browsers fill familiar fields.
